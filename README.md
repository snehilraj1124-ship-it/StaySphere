# 🏨 StaySphere — Hotel Management Platform

### Complete Hotel Operations, Reservation & Billing System

StaySphere is a full-stack hotel management platform designed to centralize and streamline hotel operations.

The application provides modules for **room inventory, guest management, reservations, dynamic room availability, occupancy tracking, billing, invoices, and operational analytics**.

It is built as a database-driven business application using Python, Flask, SQLite, Jinja2, HTML, and CSS.

---

## 🚀 Features

### 🛏️ Room Inventory Management

StaySphere provides centralized room inventory management.

Features include:

- Room registration
- Unique room numbers
- Room type management
- Nightly pricing
- Room status tracking
- Available rooms
- Occupied rooms
- Maintenance rooms
- Room inventory dashboard
